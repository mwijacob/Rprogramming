0.1 Abstract

This project looks at how population size is related to carbon dioxide (CO₂) emissions using two datasets: World Population and CO₂ Emissions. It involves checking and cleaning the data, estimating population in 2030, creating graphs to show population and CO₂ trends, and examining relationships between the variables.

The population dataset contains 234 countries and territories, while the CO₂ dataset contains 215 country records. Not all countries could be matched between the two datasets because of differences in country names and missing data.

It is important to note that CO₂ emissions are measured per person (metric tons per capita), not as each country’s total emissions. Therefore, the results show relationships involving emissions per person rather than total CO₂ output

1. Introduction

Population growth can increase the need for energy, transport, goods and other resources. These activities can contribute to CO₂ emissions. However, emissions also depend on how countries produce energy, their economic activities, technology and people’s lifestyles.

This project aims to study population trends and find out whether countries with larger populations also tend to have higher CO₂ emissions.

2. Methods and dataset

The population dataset includes country/territory, continent, population at selected years, area, density, growth rate and world population percentage. The CO2 dataset contains annual values from 1990 to 2019 and identifies the indicator as CO2 emissions (metric tons per capita). The population data are merged with the CO2 data using country names. The supplied CO2 file has both 2019 and 2019.1; this analysis uses 2019 and excludes the duplicate 2019.1 field.

3.5.1 Number of outliers per variable (IQR rule)

count_outliers <- function(x) {
  q <- quantile(x, c(.25, .75), na.rm = TRUE)
  iqr <- q[2] - q[1]
  sum(x < q[1] - 1.5 * iqr | x > q[2] + 1.5 * iqr)
}

Decision. Most outliers here are real countries (China, India, Monaco, Macau…), not mistakes, so I do not delete them. I keep the real values for the rankings and the projections. For the correlation work I make a capped copy (winsorising at the 1.5 x IQR limits) so extreme values do not dominate.

cap_iqr <- function(x) {
  q <- quantile(x, c(.25, .75), na.rm = TRUE)
  iqr <- q[2] - q[1]
  pmin(pmax(x, q[1] - 1.5 * iqr), q[2] + 1.5 * iqr)
}

4. New variable: population in 2030

Formula: \(N_t = P e^{rt}\) with P = population in 2022 and t = 2030 - 2022 = 8 years.

In this dataset Growth Rate is a yearly multiplier (for example 1.0027 means +0.27% per year). So the continuous rate is \(r = \ln(\text{Growth Rate})\).

pop <- pop %>%
  mutate(
    r = log(`Growth Rate`),
    t = 2030 - 2022,
    Pop_2030 = `2022 Population` * exp(r * t)
  )

Graph 3: CO2 emission trend 1990 to 2019

The CO2 file has one column per year, and the year 2019 appears twice. I first make the column names unique, then reshape to long format, and finally average the duplicated 2019 values so that each country has one value per year.

names(co2) <- make.unique(names(co2))     # the repeated "2019" becomes "2019.1"

country_col   <- intersect(c("Country Name", "Country", "Country/Territory"), names(co2))[1]
year_cols_co2 <- names(co2)[grepl("^(19|20)[0-9]{2}", names(co2))]

co2_long <- co2 %>%
  select(all_of(country_col), all_of(year_cols_co2)) %>%
  rename(Country = all_of(country_col)) %>%
  pivot_longer(-Country, names_to = "Year", values_to = "CO2") %>%
  mutate(Year = as.numeric(substr(Year, 1, 4)), CO2 = as.numeric(CO2)) %>%
  filter(Year >= 1990, Year <= 2019) %>%
  group_by(Country, Year) %>%
  summarise(CO2 = mean(CO2, na.rm = TRUE), .groups = "drop") %>%
  mutate(CO2 = ifelse(is.nan(CO2), NA, CO2))

Country names are written differently in the two files (for example “Russia” and “Russian Federation”), so I make them the same before joining.

co2_long <- co2_long %>%

9. Conclusion

In this project, the World Population Dataset was cleaned (duplicates, missing values and outliers) and used to project each country’s population to 2030 with the exponential growth model. The ten most populous countries were identified and their population and CO2 emission trends were visualised. Correlation analysis, a scatter plot and a log regression were used to study the link between population (2022) and CO2 emissions (2019). Finally, emissions were compared across continents. Overall, population size is related to CO2 emissions, but it does not explain them alone. The full discussion, limitations and recommendations are in the accompanying LaTeX report.
